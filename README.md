# 店舗業績ダッシュボード | 公開ポートフォリオ

松尾 春希 / 大阪公立大学 理学部 物理学科

長期インターンで関わった業務システムの経験を題材に、応募用に再構成したデモです。実案件の納品物や本番ソースコードではありません。2026年10月にAIの支援を用いて作成しました。

## 作品

- `index.html`: ブラウザで動くダッシュボード。期間・担当者を選ぶと、架空の取引データから指標を再集計します。
- `portfolio.pdf`: 課題、担当範囲、画面例、設計意図をまとめた提出用資料。

`index.html`をダウンロードしてブラウザで開いてください。外部ライブラリ、通信、認証は不要です。

## 設計意図

表示期間と担当者を明示し、来店数・成約数・成約率・買取金額を同じデータから計算します。率だけでなく母数も示し、担当者別比較と期間推移を併記します。成約がない場合もゼロと明示します。入力が不正なときは古い集計結果を隠してエラーを表示します。

## 経験との関係

実案件では、既存の受付・買取台帳システムを引き継ぎ、業務要件の整理、実装状況の確認、進捗報告・引継ぎに関与しました。案件の技術構成はGoogle Apps Script、HTML、Google Sheetsです。このリポジトリは、その経験から得た課題を、独立したサンプルとして説明するものです。

## 公開範囲と限界

すべてのデータはこのデモのために生成した架空データです。顧客名、実顧客データ、実売上、社内文書、認証情報、非公開URLは含めていません。実案件の本番稼働、効果測定、全面完成を示すものではありません。MLモデルの学習やAIによる売上予測は実装していません。
